# Fuentes locales

Estos archivos se sirven desde el mismo origen para evitar una hoja de estilos
render-blocking de Google Fonts.

- `bricolage-grotesque-latin.woff2`: Bricolage Grotesque, eje variable `wght`.
- `inter-latin.woff2`: Inter, eje variable `wght`.

Origen: Google Fonts. Ambas familias se distribuyen bajo SIL Open Font License
1.1. Los archivos son el subconjunto `latin` de Google Fonts; incluye los
caracteres acentuados del español.

Las fuentes decorativas del editor (Anton, Archivo Black, Bebas Neue y Playfair
Display) se cargan aparte, después del contenido principal, desde
`app.js`.
