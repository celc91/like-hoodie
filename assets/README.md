# Imágenes de producto

- `hoodie-front.png` y `hoodie-back.png`: maqueta fotográfica de sudadera con fondo transparente, extraída de una plantilla de **Mockup Space** (free personal & commercial use).
- `hood-mask-front.svg`: máscara para el forro de la capucha en la vista frontal.
- `hood-mask-back.svg`: máscara de referencia para la vista trasera.

Para producción, sustituye estas imágenes por fotografías reales de las sudaderas de Chama, manteniendo el fondo transparente y una composición vertical similar. Las posiciones de texto y logo se ajustan con las variables de porcentaje del editor.
