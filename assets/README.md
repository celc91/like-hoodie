# Imágenes de producto

- `hoodie-front.webp` y `hoodie-back.webp`: maqueta fotográfica de sudadera con fondo transparente, extraída de una plantilla de **Mockup Space** (free personal & commercial use). Los PNG originales se conservan por si hacen falta para impresión o edición, pero la web carga las versiones WebP.
- `hoodie-side-right.webp`: vista de perfil basada en la maqueta **Pullover Hoodie Mockup (Right Side)** de Mockup Zone / Artboard Studio. El perfil izquierdo se genera volteando esta misma imagen desde CSS.

Para producción, sustituye estas imágenes por fotografías reales de las sudaderas de like hoodie ♡, manteniendo el fondo transparente y una composición vertical similar. Las posiciones de texto y logo se ajustan con las variables de porcentaje del editor.
