## Cómo subirlos

1. **Foto de perfil:** usar `perfil-like-hoodie.png` tal cual. Facebook la recorta en círculo; el corazón, el nombre y la frase están dentro del área segura.
2. **Foto de portada:** usar `portada-like-hoodie.png`. En escritorio, la foto de perfil se superpone abajo a la izquierda; por eso el mensaje principal está centrado. En móvil se recorta al centro y se mantienen el titular, la sudadera y el botón.
3. **Botón de acción:** “Comprar ahora” → `https://likehoodie.com`.
4. **Usuario sugerido:** `@likehoodie`. Si no está disponible, probar `@likehoodie.mx`, `@holalikehoodie` o `@likehoodieoficial`.
