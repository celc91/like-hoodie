# Logo de like hoodie ♡

Todos los archivos tienen **fondo transparente** y están listos para web, impresión y el configurador de sudaderas.

## Archivos

| Archivo | Uso recomendado |
|---|---|
| `likehoodie-logo-horizontal.png` / `.svg` | Versión principal para fondos claros: web, correo, facturas, etiquetas. |
| `likehoodie-logo-horizontal-blanco.png` / `.svg` | Fondo oscuro: conserva el corazón naranja y el nombre en crema. |
| `likehoodie-logo-horizontal-negro.png` / `.svg` | Una sola tinta. Ideal para bordado, sellos o impresión monocromática. |
| `likehoodie-logo-horizontal-blanco-solido.png` / `.svg` | Una sola tinta clara para fondos oscuros, bordado o vinilo. |
| `likehoodie-logo-horizontal-tagline.png` / `.svg` | Versión con “HECHO EN MÉXICO”. Úsala en tamaños grandes; el subtítulo se pierde en tamaños pequeños. |
| `likehoodie-logo-stacked.png` / `.svg` | Versión vertical para el centro del pecho, avatares, etiquetas o empaque. |
| `likehoodie-logo-stacked-blanco.png` / `.svg` | Versión vertical para fondos oscuros. |

## Para el configurador de sudaderas

1. Entra a `likehoodie.com` y abre el personalizador.
2. En **Logo**, sube el PNG que corresponda:
   - Sudadera clara: `likehoodie-logo-horizontal.png` o `likehoodie-logo-stacked.png`.
   - Sudadera oscura: `likehoodie-logo-horizontal-blanco.png` o `likehoodie-logo-stacked-blanco.png`.
   - Bordado o una sola tinta: `likehoodie-logo-horizontal-negro.png` o `likehoodie-logo-horizontal-blanco-solido.png`.
3. Ajusta el tamaño y la posición. Para el centro del pecho suele funcionar mejor la versión **stacked**; para una franja ancha, la **horizontal**.

## Especificaciones

- PNG de alta resolución con transparencia.
- SVG vectorial con el texto convertido a trazados: no depende de que la fuente esté instalada.
- Colores: naranja `#ff4d1f`, tinta `#161618`, crema `#f4efe6`.
- Tipografía: Bricolage Grotesque 800.

## Nota

Los visores de imágenes suelen mostrar el fondo transparente en blanco. Al subir el archivo a la web o al configurador, el fondo se mantiene transparente.
